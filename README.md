# OTB Live

Open-to-Buy Inventory Planning for ApparelMagic users.

## Quick Start

```bash
npm install
npm run dev
```

## Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new)

## Upload Data

1. Export Current Inventory from ApparelMagic → upload CSV
2. Export Sales History → upload CSV  
3. View Action List for reorder recommendations

## Features

- ✅ Core vs Seasonal filtering
- ✅ 90-day lead time + 14-day buffer calculations
- ✅ Stockout risk by SKU
- ✅ Export reorder plans

Built for Corridor NYC.
